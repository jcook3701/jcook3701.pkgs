# Mkchromecast

[Mkchromecast](https://mkchromecast.com/) is an open-source, Python-based application that allows you to stream system audio and video from your macOS or Linux desktop directly to Google Cast devices and Sonos speakers. It features a system tray menu, supports high-resolution audio (up to 24-bit/96kHz), and can transcode files in real-time using node.js or ffmpeg.
