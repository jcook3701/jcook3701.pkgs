# Pulse Audio

[PulseAudio](https://www.freedesktop.org/wiki/Software/PulseAudio/?__goaway_challenge=meta-refresh&__goaway_id=3ebae4f38716a27edf7606f4b3b1c9da&__goaway_referer=https%3A%2F%2Fwww.google.com%2F) is a general-purpose Linux sound server that acts as middleware between your applications and audio hardware. It enables advanced volume control, network audio streaming, and simultaneous audio routing, running securely on a per-user basis rather than globally as root
