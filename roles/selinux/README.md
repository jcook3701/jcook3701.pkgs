# SELinux (Security-Enhanced Linux)

[Security-Enhanced Linux (SELinux)](https://github.com/SELinuxProject/selinux) is a Linux kernel security module providing Mandatory Access Control (MAC) (MAC) to restrict processes, files, and ports based on security policies, allowing only explicitly permitted actions. Originally developed by the NSA, it enhances system security, prevents privilege escalation, and is standard in Red Hat-based distributions (RHEL, Fedora, CentOS).
