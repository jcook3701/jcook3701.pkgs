# DHCPD

 [dhcpd](https://linux.die.net/man/8/dhcpd) (DHCP daemon) is a server-side application, primarily the Internet Systems Consortium (ISC) DHCP server, that runs on Linux/Unix systems to dynamically assign IP addresses and network configuration (subnet mask, gateway, DNS) to client devices. It manages "leases" for IP addresses and is commonly used to automate network configuration in enterprise and home environments.
