# Vagrant

[Vagrant](https://developer.hashicorp.com/vagrant) is an open-source tool by HashiCorp for building, configuring, and managing reproducible virtualized development environments. By using a single Vagrantfile to define machine configurations (CPU, RAM, OS), it streamlines development with consistent, portable workflows across Windows, macOS, and Linux.  

``` shell
$ ansible-playbook jcook3701.pkgs.vagrant.yml -K
```
