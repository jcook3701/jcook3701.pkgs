# fail2ban

[Fail2ban](https://github.com/fail2ban/fail2ban) is a lightweight Python-based intrusion prevention framework designed to protect Linux servers from brute-force and malicious login attempts. It operates by monitoring system and application logs in real-time, detecting repeated authentication failures, and automatically executing firewall rules (like iptables or firewalld) to temporarily block the offending IP address.
