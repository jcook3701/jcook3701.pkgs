# tftpd-hpa

[tftpd-hpa](https://manpages.debian.org/testing/tftpd-hpa/tftpd.8.en.html) is the most popular, enhanced open-source Trivial File Transfer Protocol (TFTP) server for Linux, primarily used for PXE network booting, firmware upgrades, and moving router/switch configurations. It is lightweight, handles high-load transfers efficiently, and supports both downloading and uploading
