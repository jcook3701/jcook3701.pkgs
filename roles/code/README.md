# Code

[Visual Studio Code](https://github.com/microsoft/vscode) (commonly known as VS Code) is a free, lightweight, and extensible source-code editor developed by Microsoft. Available across Windows, macOS, Linux, and web browsers, it combines the simplicity of a fast text editor with powerful developer tools like debugging, version control, and AI assistance.
