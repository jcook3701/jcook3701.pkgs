# pxelinux

[pxelinux](https://ltsp.org/guides/pxelinux/) is a bootloader from the Syslinux project used to boot operating systems like Linux over a network using the Preboot Execution Environment (PXE). It downloads the core pxelinux.0 file via TFTP, reads configuration files, and loads kernels or installers.
